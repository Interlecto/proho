# API contract

OpenAPI specification shared by the backend and all clients. It is the
source of truth for endpoints, payloads and error formats.

The exception is the accounting module, whose API is the contract shared with
Contarte. What is agreed in Contarte's `docs/api-contract/` is authoritative for
it, rather than anything defined here. See
[`docs/strategy/contarte-alignment.md`](../docs/strategy/contarte-alignment.md).
