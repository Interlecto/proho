# Legacy implementation (2016)

The original PHP version of ProHo, kept for reference while the new platform
is built. It is not maintained and not part of any build.

- `dist/` — PHP application (front controller, API, install scripts, modules)
- `dev/` — module notes (accounting, messaging, publishing, security, …)
- `maqueta/` — static HTML mockups of the original screens (Spanish UI)

What the new platform takes from this code is recorded in
[docs/legacy-salvage.md](../docs/legacy-salvage.md).
